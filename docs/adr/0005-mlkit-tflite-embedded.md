# ML Kit + TFLite embedded, offline dal primo avvio

OCR via ML Kit Text Recognition v2 on-device; classifier come asset embedded (gazetteer OSM + regole + TF-IDF/LogReg quantizzato TFLite <10MB, fallback keyword scoring se modello assente). Modello bundlato in app, inference <500ms, zero rete, sample receipts inclusi per demo senza foto.
